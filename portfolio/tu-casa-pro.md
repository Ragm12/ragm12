# Tu Casa Pro

**Tipo:** Aplicación para propiedad horizontal  
**Demo:** https://tucasapro.app/co

## Problema

Centralizar tareas comunes de administración residencial en una sola experiencia digital y reducir fricción para residentes y administración.

## Solución

Desarrollé una aplicación orientada a propiedad horizontal que reúne operación administrativa y autoservicio para residentes, incorporando además un asistente de IA.

## Funcionalidades principales

- Asistente de IA
- Pagos
- Cartera
- PQRS
- Gestión de zonas comunes
- Flujos de administración y consulta para residentes

## Qué demuestra

Este proyecto muestra capacidad para diseñar producto alrededor de procesos operativos reales, conectar múltiples módulos dentro de una misma aplicación y aplicar IA en una experiencia de usuario concreta.
