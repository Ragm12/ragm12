# Manufacturas Mego

## Resumen

Manufacturas Mego es un sitio comercial y catálogo digital para una empresa de productos industriales, dotaciones y seguridad.

**Producto:** https://manufacturasmego.com

## Problema

La empresa necesitaba una presencia digital clara para presentar su oferta, organizar categorías de producto y facilitar el contacto comercial con clientes B2B.

## Solución

Se construyó un sitio orientado a catálogo y generación de oportunidades comerciales, con estructura de navegación simple y contacto directo.

### Funcionalidades destacadas

- catálogo digital;
- organización por categorías;
- presentación de productos industriales y dotaciones;
- contacto comercial;
- identidad visual aplicada al canal digital;
- experiencia responsive.

## Rol

Desarrollo del producto digital y adaptación de necesidades comerciales a una solución web utilizable por clientes reales.

## Estado del código

El proyecto se encuentra desplegado en ChatGPT Sites. El código fuente se mantendrá privado al migrarse a GitHub y se revisará configuración, datos de contacto e integraciones antes de preparar cualquier versión pública.

## Qué demuestra

- desarrollo web para negocio B2B;
- estructuración de catálogos;
- integración entre producto, marca y proceso comercial;
- construcción de soluciones para empresas reales.
