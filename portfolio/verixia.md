# Verixia

**Tipo:** SaaS B2B legaltech  
**Demo:** https://www.verixia.app

## Problema

Construir una base de producto legaltech que permitiera presentar el servicio, gestionar contactos, preparar un portal autenticado y generar reportes digitales de forma mantenible.

## Solución

Desarrollé una aplicación web con arquitectura full stack sobre Next.js App Router, con persistencia en Supabase y despliegue en Vercel.

## Stack

- Next.js 16
- TypeScript
- Tailwind CSS
- Supabase
- Vercel

## Componentes técnicos

- Landing pública
- Login y base de dashboard
- Formulario de contacto con API route
- Preview de reportes
- Generación de PDF desde reportes
- Migraciones de base de datos
- Documentación de despliegue
- Registro de incidentes y cambios
- Checklist de release

## Qué demuestra

Este proyecto muestra mi capacidad para llevar un producto desde interfaz y experiencia de usuario hasta backend, datos, APIs, documentación operativa y despliegue.
